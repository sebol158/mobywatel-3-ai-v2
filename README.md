# mObywatel 3.0 AI — Wersja 2.0 (Calm UI 2026)

Kompletna wersja konkursowa prototypu na **mObywatel Challenge (`mobywatel.ai`, termin: 30.11.2026)**, zaprojektowana zgodnie z trendami **GOV.UK Plain Language**, **Apple Calm UI**, **App IO** i **Diia**:

1. **Zero duplikacji i prosty język:** 4 zakładki (`Start`, `Dokumenty`, `Usługi`, `Asystent`), przełącznik `Obywatel ⇄ mFirma` u góry, pojedyncze godło RP oraz spójne ikony SVG.
2. **Stos Dokumentów + żywy zegar + hologram RP:** `mDowód` (odsłanianie danych, zastrzeżenie PESEL, Znak 18+ ZKP), **Dowody dzieci (`mDowód dziecka` + `mLegitymacja` + `IKP` + cyfrowa zgoda rodzica)**, `Moje pojazdy`, `mPrawo jazdy`, `Karta Dużej Rodziny`.
3. **Cztery głośne usługi 2026:**
   - **Tarcza „Kto dzwoni?”** (weryfikacja banku/Policji + zgłoszenie spoofingu do CERT Polska).
   - **Księgi Wieczyste 2.0** (bezpłatny podgląd KW, Alert KW i wykreślenie hipoteki 1-klikiem).
   - **Moja Emerytura 360°** (`ZUS + PPK + OFE + IKE` z symulacją +2 lat pracy).
   - **Skaner PDF + Podpis ręczny i Profil Zaufany + „Wyślij do…”** (skan/zdjęcie A4 → generacja prawdziwego `.pdf`, naniesienie podpisu w wybrane miejsce, pieczęć PZ i wysyłka przez e-Doręczenia/e-mail/SALDO).
   - **Start firmy „1 Okienko”** w `mFirma` (`CEIDG-1 + VAT-R + ZUS + ADE + KSeF`) obok `KSeF Alert`, `e-Doręczeń` i `Corppass PL`.
4. **Dark Mode, Tryb Wysokiego Kontrastu Czarno-Żółty (WCAG AAA >16:1), wyszukiwarka `<search>` w `Usługach`, PWA (`manifest.json`) i 6-krokowy pokaz z przewodnikiem dla Jury.**
5. **`figma-svg/*.svg`:** **15 makiet wektorowych (`393×852 px`)** gotowych do wklejenia na kanwę Figmy.
